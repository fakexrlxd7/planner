Квест-планнер

Два отдельных планнера с отдельными данными. Открой нужный и добавь его на главный экран телефона.

Работапроекты, смены, встречи, цели
Личноедела на день, привычки, записи, хотелки
iPhone: открой планнер в Safari → «Поделиться» → «На экран Домой».
Android: Chrome → ⋮ → «Добавить на главный экран» или «Установить приложение».
Данные хранятся на устройстве и синхронизируются через твой приватный GitHub Gist (Настройки → Синхронизация).
