# Квест-планнер: как поставить на ПК и телефон

В комплекте два отдельных планнера, **Работа** и **Личное**. У каждого свои данные, они никак не смешиваются.

## Вариант 1. Только компьютер, без настройки

Скопируй `Планнер-Работа.html` на рабочий (удалённый) стол, а `Планнер-Личное.html` на личный. Открой двойным щелчком в Chrome или Edge.

Данные хранятся в браузере этого компьютера. Раз в неделю нажимай «Настройки → Скачать копию».

Чтобы планнер открывался отдельным окном, как программа, сделай ярлык с такой командой:

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --app="file:///C:/Users/ИМЯ/Desktop/Планнер-Работа.html"
```

## Вариант 2. ПК и телефон с общими данными (рекомендую)

### Шаг 1. Разместить планнер в интернете (бесплатно, 5 минут)

1. Зарегистрируйся на https://github.com.
2. Нажми «+» → **New repository**. Назови его `planner`, выбери **Public** и нажми **Create repository**.
   В репозитории лежит только программа. Твои данные хранятся отдельно и зашифрованы, в репозиторий они не попадают.
3. На странице репозитория нажми **uploading an existing file** и перетащи все файлы из папки `quest-planner` этого архива. Затем нажми **Commit changes**.
4. Открой **Settings → Pages**. В Source выбери **Deploy from a branch**, ветку **main**, папку **/(root)** и нажми **Save**.
5. Через 1–2 минуты планнер будет доступен по адресу `https://ТВОЙ-ЛОГИН.github.io/planner/`.

### Шаг 2. Включить синхронизацию

1. Открой https://github.com/settings/tokens/new?scopes=gist. Отметь только галочку **gist**, срок поставь «No expiration», нажми **Generate token** и скопируй токен.
2. На ПК открой планнер (по ссылке или из файла) и перейди в **Настройки → Синхронизация**. Вставь токен, придумай **пароль шифрования** и нажми «Подключить».
3. Нажми «Скопировать код подключения» и отправь код себе, например в «Избранное» мессенджера.
4. На телефоне открой `https://ТВОЙ-ЛОГИН.github.io/planner/` и выбери нужный планнер. В Настройках вставь код и введи **тот же пароль**.
5. Добавь планнер на главный экран:
   - iPhone: Safari → «Поделиться» → «На экран Домой».
   - Android: Chrome → ⋮ → «Установить приложение».

Изменения синхронизируются сами: через 2–3 секунды после правки, раз в минуту и при открытии приложения. Без интернета всё сохраняется на устройстве и отправится, когда связь появится. Если правки сделаны на двух устройствах одновременно, они **объединяются**, а не затирают друг друга.

### Безопасность

- Данные шифруются AES-256 твоим паролем ещё до отправки. Без пароля в gist не прочитать ничего, в том числе GitHub.
- Пароль хранится только на твоих устройствах. Если его забыть, данные в gist не восстановить. Поэтому иногда скачивай резервную копию.
- Код подключения содержит токен, не публикуй его. Если код утёк, удали токен на https://github.com/settings/tokens и создай новый.
- Работу и личное можно держать в одном gist (это разные файлы) или подключить разными токенами.

### Если на работе закрыт доступ к GitHub

Тогда рабочий планнер синхронизироваться не сможет и будет работать локально, как в варианте 1. Личный планнер на телефоне и домашнем ПК синхронизируется как обычно.

## Как обновить планнер на GitHub, когда выходит новая версия

Твои задачи при обновлении **не пропадают**: они хранятся в браузере и в зашифрованном gist, а не в файлах на GitHub.

1. Распакуй новый архив `quest-planner-github-pages.zip`.
2. Открой свой репозиторий `github.com/ЛОГИН/planner` на вкладке **Code**.
3. Справа нажми **Add file → Upload files**.
4. Перетащи **все файлы из папки `quest-planner`** (не саму папку). Файлы с теми же именами заменятся.
5. Внизу нажми **Commit changes**.
6. Подожди 1–2 минуты. Ход публикации видно во вкладке **Actions**: зелёная галочка значит готово.
7. Обнови страницу планнера на ПК (Ctrl+F5). На телефоне закрой приложение полностью и открой снова. Если версия всё ещё старая, закрой и открой ещё раз.

Номер версии написан внизу раздела «Настройки».
